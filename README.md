# SIGEB — Sistema de Gestión Bibliotecaria

Prototipo web de los Sprints 0 y 1 para la gestión de usuarios, gestión de libros y búsqueda de libros.

## Tecnologías

- **Frontend:** Next.js 15, React 18 y TypeScript.
- **Estilos:** CSS responsive en `app/globals.css`.
- **Base de datos:** PostgreSQL 14+.
- **Conexión:** `pg` mediante la variable `DATABASE_URL`.
- **Esquema:** `baseDeDatos.sql`.
- **Datos iniciales:** `datos.sql`.

El esquema SQL utiliza sintaxis compatible con PostgreSQL, incluyendo columnas `GENERATED BY DEFAULT AS IDENTITY` y tipos `TIMESTAMP`.

## Requisitos

Instala previamente:

- Node.js 18.18 o superior.
- npm 9 o superior.
- PostgreSQL 14+ para cargar la base de datos.

Puedes comprobar las versiones con:

```bash
node --version
npm --version
psql --version
```

## Instalación del proyecto

Desde la carpeta raíz del proyecto:

```bash
npm install
```

Copia `.env.example` como `.env.local` y configura la conexión:

```env
DATABASE_URL=postgresql://postgres:tu_contrasena@localhost:5432/sigeb
```

## Ejecutar localmente

Inicia el servidor de desarrollo:

```bash
npm run dev
```

Después abre [http://localhost:3000](http://localhost:3000).

Para generar y probar la versión de producción:

```bash
npm run build
npm start
```

La aplicación consulta PostgreSQL mediante las rutas `/api/catalog`. Los nuevos usuarios y libros se guardan en la base de datos y permanecen después de reiniciar el servidor. Si PostgreSQL no está disponible, la interfaz muestra el error de conexión en lugar de ocultarlo.

## Configurar la base de datos

1. Crea una base de datos vacía desde el usuario administrador:

   ```sql
   CREATE DATABASE sigeb;
   ```

   Desde la terminal también puedes ejecutar:

   ```bash
   createdb -U postgres sigeb
   ```

2. Ejecuta el esquema:

   ```bash
   psql -U postgres -d sigeb -f baseDeDatos.sql
   ```

3. Carga los datos de desarrollo:

   ```bash
   psql -U postgres -d sigeb -f datos.sql
   ```

Si tu instalación utiliza otro usuario, host o puerto, agrega las opciones correspondientes, por ejemplo `-h localhost -p 5432 -U mi_usuario`.

También puedes ejecutar ambos archivos desde pgAdmin, seleccionando primero `baseDeDatos.sql` y después `datos.sql`.
